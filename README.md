# RASHD AI

### AI-Powered Personal Finance Intelligence & Decision Support Platform

RASHD AI is a fintech platform designed to help users understand their financial behavior, evaluate spending decisions, and make more informed choices using data-driven financial intelligence and AI-assisted guidance.

Rather than relying on an LLM to perform financial calculations, RASHD separates deterministic financial analysis from the AI explanation layer. Financial indicators and behavioral signals are calculated using structured logic, while AI is used to transform those results into clear, user-friendly guidance.

---

## Overview

Managing personal finances is not only about tracking expenses. Users also need to understand spending patterns, evaluate whether purchases are financially appropriate, protect savings, and work toward financial goals.

RASHD AI combines financial analytics, behavioral insights, decision-support logic, and an interactive dashboard to provide a more intelligent personal finance experience.

---

## Key Features

### Financial Dashboard
Provides an overview of the user's financial position, including:

- Current balance
- Income and spending
- Budget utilization
- Fixed and variable commitments
- Savings progress
- Financial indicators

### Behavioral Spending Analysis
Analyzes transaction patterns to identify potentially impulsive or unusual spending behavior.

Signals include:

- Late-night purchases
- Repeated purchases within short periods
- Spending above category averages
- Non-essential spending patterns

The analysis produces structured, testable signals before any AI-generated explanation is created.

### Affordability Engine
Evaluates a potential purchase before the user makes it.

The engine considers factors such as:

- Current balance
- Remaining category budget
- Monthly budget utilization
- Financial commitments
- Savings context
- Estimated financial risk

It then generates an affordability assessment and risk level to support better purchasing decisions.

### Savings & Goal Intelligence
Helps users track financial goals and understand their progress toward target amounts.

### AI Financial Assistant
Provides natural-language explanations based on the financial signals generated by RASHD's analysis engine.

The assistant is designed to explain existing financial data rather than invent or independently calculate financial information.

### Transactions & Reports
Allows users to explore transaction activity and financial insights across different time periods.

## How RASHD Works

```text
Financial / Synthetic Data
          |
          v
  Data Processing Layer
          |
          v
Financial & Behavioral Analysis
          |
          +----------------------+
          |                      |
          v                      v
 Dashboard Indicators     Decision Engines
                          - Spending Analysis
                          - Affordability
                          - Savings Goals
          |                      |
          +----------+-----------+
                     |
                     v
             Structured Signals
                     |
                     v
          AI Explanation Layer
                     |
                     v
        User-Friendly Financial Guidance
```

This architecture keeps financial calculations deterministic and testable while using AI primarily for explanation and interaction.

## Scenario-Based Testing

RASHD includes a scenario-testing layer that allows the financial intelligence logic to be evaluated independently of the user interface.

Current scenarios include:

1. Dashboard financial overview
2. Behavioral / impulsive spending detection
3. Affordable purchase evaluation
4. High-risk purchase evaluation
5. Savings goal recommendations
6. Financial assistant interaction

Run the scenarios with:

```bash
node scenarios/runScenarios.js
```

## Run Locally

Clone the repository:

```bash
git clone https://github.com/ElafFareed/RASHD-AI.git
cd RASHD-AI
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```
